# APEX 代码研究与整体优化清单

审查日期：2026-09-05。对象：用户提供的 `APEX_乳腺AI平台_2026-09-01.zip`，解包到 `source/breast_roi_copilot`。本轮没有修改原始应用代码，也没有向在线模型发送患者资料。

## 结论

现有工程适合作为业务逻辑和演示验证的基础，不宜仅换皮后直接开放真实患者使用。最值得保留的是独立 Python ROI 内核、Pydantic 数据约束、人工核对逻辑和报告校验；最需要改造的是账户与持久化、资料版本、AI 到人工确认的边界、照护状态以及手机操作路径。

建议先完成患者资料与照护闭环，再扩大机构端能力。患者端应是默认入口，机构端采用独立入口与授权，不继续把“切换工作区”当成访问控制。

## 当前能力与数据流

### 患者端

入口注册了我的档案、照护报告、照护日历、知识问答四页。`src/patient_companion` 集中了资料解析、模型提取、来源验证、核对、任务、报告和知识检索。

```text
PDF / DOCX / TXT
  → documents.parse_document：文件文字与页码
  → provider.extract_case_with_openai：结构化档案、事实、事件
  → validation.validate_case_provenance：引用文字/文档/事实ID验证
  → session_state.patient_case
  → review.apply_fact_review：逐条事实确认 → 推导事件确认
  → report.build_report / tasks.build_care_tasks
  → session_state.patient_task_status

知识JSON → 字符二元组检索 → 已检索片段 → 模型回答或演示摘录
                                      → 引用ID集合检查 → 页面展示
```

| 能力 | 状态 | 改造价值 |
|---|---|---|
| 文字型文件解析、结构化提取、事实引用 | 已实现，但验证边界不足 | 保留结构，扩展解析和字段级来源 |
| 事实确认、关联事件状态推导 | 已实现 | 保留纯函数，加入服务端授权与版本检查 |
| 照护报告、日历、状态切换 | 已实现，会话内有效 | 改为持久记录，区分事件与执行实例 |
| 知识问答 | 本地少量知识片段、词面检索、可选实时模型 | 增加可审核知识版本、结构化会话和检索评测 |
| 演示病例 | provider 和测试存在 | 当前档案页没有 README 所说的“加载模拟病例”入口，应修正文档或补独立演示入口 |
| 症状记录 | 有 `SymptomCheckIn` 类型 | 未发现对应完整页面闭环，不能计为已上线能力 |
| OCR、登录、持久档案、跨设备恢复、家属权限 | 未实现 | OCR/登录/持久化是目标首版新增；家属协作不在首版范围 |

### 机构端

当前导航是 AI 决策助手、上传与检查、证据与参数、高级 ROI 仿真、外展资源优化。工程还保留独立的证据提取、参数助手、模型性能、AI 评测、管理报告等页面文件；这些不等于当前导航都能访问，其中部分能力已合并到主流程。

```text
医院CSV → 校验/派生字段 → 人工应用 → 会话中的人群与元数据
  → 场景与缺失参数 → PubMed检索/AI提取 → 人工审核证据库
  → 确认的ROI输入快照 → Python确定性计算 → 敏感性分析
  → AI报告草稿 → 数字/引用检查 → 展示

参数/证据决策 → 本地CSV + JSONL审计
外展优化 → 上传人群或合成人群 → 规则/假设模拟
```

PubMed 客户端是真实 HTTP 集成并含超时；证据页有缓存。ROI 不依赖 LLM 计算，值得保留。外展页面能读取已上传人群，但完成概率等仍可能是规则派生值，不能因为上传了医院数据就称为已验证预测模型。ROI 默认范围是 40–74 岁 DBT，现有美元成本和特定参数口径不能直接替换货币符号后称为本地适用模型。

## 实施顺序与完成标准

1. 风格选定后完成患者原型与字段状态设计，明确OCR和模型的境内服务边界。
2. 先建设账户、文档存储、版本及异步作业，再连接真实提取服务；开发验证使用虚构/脱敏夹具。
3. 打通核对、持续档案、今日安排与有来源问答；完成P0及影响核心流程的P1。
4. 补机构API、事务存储和ROI快照回归；未本地校准的参数与外展结果持续标注假设性质。
5. 通过访问隔离、刷新恢复、冲突处理、删除流程、失败恢复和浏览器验收后，再开放受控真实资料试用。

本轮交付的是研究与选型材料、复现证据和六张生图，不是已完成上述产品改造。供应商、详细API契约、工期与成本在你选择视觉方向后集中定稿。
