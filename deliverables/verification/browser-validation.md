# 浏览器验收记录

时间：2026-09-06。使用本机 `http://127.0.0.1:5173`，FastAPI 8000，独立虚构演示账户。通过 Codex 浏览器实际操作，非静态源码推测。

| 操作 | 观察结果 |
|---|---|
| 打开演示首页 | 珊瑚红页面、盆栽/清单/心形插画正常显示，初始3项待核对 |
| PC核对页 | 原文高亮与事项双栏；明确复诊日期09:00可见 |
| 确认一条复诊事项 | 待核对数3→2，界面切到下一事项，计划中新增对应任务 |
| 将任务设为已完成 | 已完成筛选显示该任务；状态保存提示出现 |
| 刷新后重新进入已完成筛选 | 同一任务仍为已完成，原档案保留 |
| 手机390×844视口 | 底部四项导航；调整了状态控件挤压正文的问题；DOM横向宽度375=scrollWidth375，无横向页面溢出 |
| 手机问答 | 提交复诊准备问题，返回明确标识的知识原文，3个来源可展开；输入框与底部导航可见 |
| 机构测算 | 默认参数算出净节省617,878.2、ROI40.2%；保存方案，情景与敏感性表显示 |
| 浏览器上传虚构CSV | 1行检查通过，缺省可选字段和小样本提醒可见；不展示患者ID |
| 浏览器上传虚构TXT | 显示排队，后台整理完成后新增3项待核对；原先资料仍在；原文可读 |

边界：这些结果不证明真实OCR识别质量、真实模型连通性、生产负载、PostgreSQL部署或云端备份删除。图片/PDF原件接口已做授权和MIME测试；完整多浏览器PDF内嵌行为仍需扩大验收。

账户切换收口：退出操作实际返回登录页；代码增加请求会话代次检查，旧请求不会写入新账户状态，退出同时清空摘要、原文、上传及删除弹窗。
